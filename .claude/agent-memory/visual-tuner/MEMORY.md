# visual-tuner 메모리 — 모구 시리즈 시각 문법과 튜닝 교훈

## 시리즈 시각 정체성
- 모구 = 실제 고양이 사진. 밈 감성의 핵심: 도트/복셀 게임 세계 + 실사 모구 사진 합성.
  - 3D 게임(어디가): 배경 제거한 모구 사진을 카메라 방향 빌보드 스프라이트로.
  - 도트 게임(머슬 등): 인게임 스프라이트는 도트로 그리되 **타이틀 아이콘만 모구 사진 유지**.
- 에셋 원본: `game/assets/mogu.png`, `game/assets/mogu-icon.png` (여러 게임이 재사용).

## 원작 유사화 패스 방법론 (mogumuscle Loop A~E에서 확립)
- 참고 이미지(원작 캡처)는 저작권 자료라 gitignore — 저장소 밖 로컬에만 있다. 경로는 사용자에게 확인.
- 진행 방식: 패스(Loop A, B, C…) 단위로 소수 파라미터만 변경 → `test/dbg-*.png` 재캡처 → 참고 이미지와 나란히 비교. 무대/포즈/HUD 등 영역별로 패스를 나눈다.
- 비교 항목화: 색 팔레트 / 비율·체형 / 포즈·실루엣 / 배경·무대 / HUD 배치.

## 확립된 도트 렌더 규칙 (mogumuscle에서 검증됨)
- 저해상도 캔버스(머슬: 480×270)에 도트 렌더, 스크린샷은 1280×720.
- 무대 분리: 주 무대(링)를 어두운 주변 + 짙은 해자(모트)로 분리하면 주목도가 산다. 로프류는 어두운 backing 위 굵은 밝은 색(주황 3줄)으로 대비 확보.
- 배경 인물은 명도를 낮춰 후경화 — 플레이어/적 가독이 항상 우선.
- 화면 압박감: 관중석 같은 배경을 화면 폭 전체의 다단 띠로 배치.
- 스프라이트: 2등신 측면 프로필, **주둥이·부리·코를 보는 쪽에만** 그려 앞뒤가 실루엣만으로 구분되게.
- 동작 가독성: 기술마다 실루엣을 분리(라리아트=팔 수평 풀스윙, 백드롭=양팔 번쩍, 드롭킥=수평 비행 두 발). 피격은 몸 전체 리코일 — 텍스트 없이 타격이 읽혀야 한다.
- 파워업 표현: 팔레트 스왑 점멸(살구→황금).
- HUD: 검은 아케이드 상단 바, 게이지 색 규칙 고정(3칸+ 초록 / 2칸 노랑 / 1칸 빨강), 텍스트 의존 최소화.

## 포즈·접지 교훈 (커밋 히스토리에서)
- 다운/눕는 자세: 옆 얼굴을 세우고 목이 몸통을 향하게 — 사진 파츠를 눕힐 때 해부학적 연결을 지켜야 자연스럽다 (모구맨 머슬 17b00b3, 215d199).
- 스프라이트 접지: 꼬리 시작점(몸의 최하단 기준점)이 그림자에 닿아야 떠 보이지 않는다 (남극 대모험 faf2dc0).
- 비행/공중 포즈는 한 가지 자세로 통일하면 정체성이 생긴다 (FBA 비행 = 드롭킥 수평 자세 통일, 7cb6db2).
- 방향 시인성이 약하면 발밑 방향 마커 같은 보조 표시를 추가한다 (4c42dda).

## 캐릭터 구분 규칙
- 진영 구분은 실루엣+색 둘 다로: 고양이(모구=태비) vs 쥐(접시귀+팀 색 마스크), 꼬꼬=볏+부리 (221d9fc).

## 3D 게임 (어디가, 마블, 킹덤)
- 복셀 블록 월드는 InstancedMesh. 어디가의 모구는 사진 빌보드.
- 마블: 보드 중앙 이미지를 고양이 사진으로 교체한 전례 — 중앙 장식은 실사 사진이 어울린다 (e43002e).
